# seeds — the wave-1 arm library

`arms.json` is the ops-readable mirror of the machine seed in
`src/arms/arms.mlog` (naryad Н1-04). The entity list `kamerton_arms`
in that file is the SSOT; the JSON is regenerated by `json_encode`
from it, and a lockstep test pins the two byte-for-byte — editing one
side without the other fails CI.

## Contents: 5 methodologies × 2 windows = 10 arms

| Group | Window | Prior (mean ± sd) | Source |
| --- | --- | --- | --- |
| Резонансное дыхание | morning / evening | 0.6 ± 0.15 | Lehrer & Gevirtz 2014 (Front Psychol 5:753) |
| Имплементационные намерения (WOOP) | morning / evening | 0.6 ± 0.15 | Gollwitzer & Sheeran 2006 (Adv Exp Soc Psychol 38) |
| Ментальная репетиция | morning / evening | 0.5 ± 0.15 | Driskell, Copper & Moran 1994 (J Appl Psychol 79(4)) |
| Фокусинг | morning / evening | 0.45 ± 0.20 | Hendricks 2002 (experiential review) |
| Йога-нидра | morning / evening | 0.45 ± 0.20 | Moszeik, von Oertzen & Günther 2022 (Current Psychology) |

Prior mapping: strong → 0.6 ± 0.15, medium → 0.5 ± 0.15,
medium-weak → 0.45 ± 0.20 (continuity with the previous iteration's
seed). Both windows share the methodology prior: the window is a
variable of the experiment, not a separately documented effect.

Duration is fixed at 10 minutes for every arm (wave-1 canon).

## Deliberately NOT in the seed

- **Самогипноз** — reserve.
- **Бинауральные и изохронные тоны**, **несущие тона 432/528 Гц** —
  sound arrives in M3.

The tests in `src/arms/arms.mlog` assert their absence, so a silent
addition fails CI.

## Idempotency

`seed_arms()` creates a UNIQUE index on `arm.name` and inserts with
`INSERT OR IGNORE` — a repeated run changes nothing, no duplicates.
The statement sequence is unrolled on purpose: the v0.28.1
interpreter runs exactly one iteration of a loop placed inside a
pattern body (declared loudly per AGENTS §2 — minimal repro in the
Н1-04 PR). A per-arm verification test pins every unrolled row to the
entity list, so the unrolled copy cannot drift silently.
