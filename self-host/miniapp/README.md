# self-host/miniapp — Mini App (страница практик)

Страница практик фазы M2 (концепция: `docs/concept-v2.md`): пейсер дыхания
и PPG через камеру — HTML/JS в браузере телефона, единственное разрешённое
исключение из §1 AGENTS.md. Вычисления исполняются на устройстве владельца;
RR-ряд наружу не уходит (инвариант 7).

## Канал доставки

ADR-0002, вариант (а) «приватный туннель»: телефон входит в приватную сеть
владельца (WireGuard/Tailscale), страницу отдаёт `mlog serve` Камертона
маршрутом `GET /miniapp`. Порты наружу остаются ноль; https внутри tailnet
делает возможной кнопку Mini App позже.

## Авторизация

Токен владельца: переменная `KAMERTON_MINIAPP_TOKEN` (deploy/env.allowlist —
SSOT; при деплое добавить строку в `/data/kamerton/env` И дополнить значение
`METALOGOS_ENV_ALLOWLIST` — установленный env-файл install.sh не
перегенерирует). Токен передаётся параметром `t` в адресе страницы:

```
https://<tailnet-адрес>:8461/miniapp?t=<KAMERTON_MINIAPP_TOKEN>
```

Каждый запрос к сессионному API несёт тот же параметр. Дополнительно
маршруты закрыты csrf-мидлварью (double-submit №262): GET страницы выдаёт
куку `_mlog_csrf`, каждый POST обязан нести её значение в `X-CSRF-Token`
(страница делает это сама; TTL 15 минут — при истечении страница
перезагружается). Мутации POST-маршрутов без куки/заголовка отвечают 403.

Токен — alphanumeric (мост `escape_html` над `query_param` точен для такого
алфавита); не используйте в нём `& < > " '`.

## Состояние на Н2-03 (скелет)

- `index.html` — канон страницы; отдаётся из ДОВЕРЕННОГО литерала в
  `src/miniapp/miniapp.mlog` (`miniapp_html()`), байт-равенство пиннуто
  тестом lockstep (read_file-результат не отвечает на запросы — граница
  утечки №391).
- Экраны пейсера и PPG — каркасы: логика ритма входит нарядом Н2-04,
  съёмка пульса и RR-ряд — Н2-05.
- Журнал сессий работает целиком: `POST /miniapp/session` открывает строку
  в таблице `practice_session` (SQLite, инвариант 6), «Отметить шаг» пишет
  отметку инкрементально, «Завершить» закрывает. Читается любым sqlite3
  клиентом.

## Сессионное API (сводка)

| Маршрут | Параметры | Ответ |
|---|---|---|
| `GET /miniapp` | `t` | HTML-страница (или 403) |
| `POST /miniapp/session` | `t, kind=pacer\|ppg, tempo_bpm, steps_total, arm_id?, trial_id?` | `{"id":N}`; 400 при мусоре |
| `POST /miniapp/session/close` | `t, id, steps_done, step_marks(JSON), rr_json(JSON), rr_source=ppg\|manual` | `{"updated":1}`; 404 — неизвестный id |

Тела запросов не используются: на 0.30.0 парсеры тела
(`json_body`/`form_data`/`request_body`) возвращают пустую структуру
(заявлено громко в worklog наряда, задание агенту Metalogos-), поля идут
процент-декодированными query-параметрами.
