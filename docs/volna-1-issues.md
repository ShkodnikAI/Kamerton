# Волна 1 — тексты issue

Восемь нарядов, без коллизий same-file. Волна закрывается только при ALL GREEN.
Цель волны — замкнутый цикл: без HRV, без звука, без Луны в выборе, без притока
исследований.

**Волна не стартует, пока не принята волна 30 Metalogos.** Блокирующие наряды
языка названы в разделе «Связь» каждого наряда.

Конструкция награды, источники «отклика в моменте» и правило молчания —
ADR-0001 (`docs/adr/0001-reward-construction.md`).

Заголовок issue = строка после `##`. Тело — шесть полей формы Ш1.
Все восемь помечаются label `волна-1` плюс указанный в наряде.

Язык реализации — Metalogos. Упёрлись в отсутствующую возможность — протокол
затыка из `AGENTS.md` §2: остановиться и заявить громко.

## Н1-02 · Запуск на домашнем сервере

Labels: `наряд`, `волна-1`, `инфра`

**Шаг 0.** Снять версию Windows и сборку WSL2; убедиться, что машина не уходит
в сон и не гасит диск; зафиксировать список имён в `METALOGOS_ENV_ALLOWLIST`.

**Факт.** Сервер работает 24/7, аренда не нужна; инвариант 7 выполняется
физически. Чтение окружения в теле маршрута закрыто по умолчанию и требует
явного allowlist.

**Задача.** WSL2 с Ubuntu; `mlog serve app.mlog` под systemd внутри WSL;
автостарт после перезагрузки Windows; база на `/data`; еженедельный бэкап на
внешний носитель.

**Сделано когда.** После принудительной перезагрузки Windows сервис
поднимается сам без ручных действий; баннер `serve` при старте печатает
состояние exec- и env-гейтов и оно совпадает с ожидаемым; бэкап-скрипт
восстанавливает базу в чистую директорию и `sqlite3` её читает.

**Границы.** `deploy/`, `self-host/`.

**Связь.** Требуется для Н1-06. Зависимостей от языка нет.

## Н1-03 · Схема хранения

Labels: `наряд`, `волна-1`, `ядро`

**Шаг 0.** Сверить таблицы с разделом «Проба, данные, движок» концепции;
проверить, какой вариант принят в наряде языка №593; сверить поля награды
и предсказания с ADR-0001.

**Факт.** Схемы нет. DDL-replay в языке аддитивен: только
`CREATE TABLE IF NOT EXISTS`, drop и alter вне контура. Необратимый SQL
требует гранта. Инвариант 6 требует читаемости сторонним клиентом.

**Задача.** Шесть таблиц — `note`, `trial`, `arm`, `response`, `context`,
`candidate` — индексы, внешние ключи, экспорт в CSV. Параметризованные
запросы: нелитеральный SQL отвергается компилятором, это норма, а не помеха.
Поля конструкции награды и предсказания по ADR-0001: флаг присутствия
компонент, источник «отклика в моменте», статус пропуска, предсказание до
пробы (глубина + уверенность 0–1); импорт базы M0 из CSV фиксированной
структуры.

**Сделано когда.** Миграция применяется идемпотентно, повтор ничего не ломает;
откат — по варианту, принятому в №593, и критерий приёмки здесь приводится в
соответствие с ним в том же PR; экспорт даёт шесть CSV; второй метод —
`sqlite3` читает схему без документации; импорт M0 даёт те же строки, что
прямой ввод; пропуск хранится строкой, а не отсутствием записи.

**Границы.** `migrations/`, `src/store/`.

**Связь.** Вход для Н1-04, Н1-05, Н1-06, Н1-07. Блокирован языком: **№593**.

**Границы.** `src/arms/`, `seeds/`.

## Н1-05 · Бандит

Labels: `наряд`, `волна-1`, `ядро`

**Шаг 0.** Убедиться, что Н1-03 и Н1-04 приняты, а в языке приняты **№590**
(гауссово сэмплирование) и **№594** (паритет тика и маршрута).

**Факт.** Ядро детерминированное, к зоне модели не относится, закрыто для
`adapt` по инварианту 1. Бандит считается в cron-тике, а отчёт отдаётся
маршрутом — это разные исполнительные пути, их паритет обеспечен нарядом
языка №594.

**Задача.** Сэмплирование Томпсона на гауссовых апостериорах через
`normal_sample` поверх общего PRNG; принудительная разведка не менее 20%;
экспоненциальный распад откликов старше 60 дней; награда — нормированная
взвешенная сумма присутствующих компонентов (ADR-0001).

**Сделано когда.** Сходимость к лучшей руке на синтетике; доля разведки на
1000 прогонов в коридоре 20–25%; мутационная проверка — убранный распад
ловится тестом; фиксированный seed даёт воспроизводимый прогон; результат
в cron-тике и в маршруте идентичен.

**Границы.** `src/bandit/`, `tests/bandit/`.

**Связь.** Ядро системы. Блокирован языком: **№590**, **№594**.

## Н1-06 · Telegram-цикл на long polling

Labels: `наряд`, `волна-1`, `инфра`

**Шаг 0.** Проверить, что токен читается из окружения через allowlist, а не из
кода; убедиться, что в языке принят **№592** (пер-вызовный таймаут).

**Факт.** Вебхука нет и не будет: публичный адрес отсутствует, приложение само
опрашивает Telegram. Владелец получает предложение в 7:00 и даёт отклик
до 02:00 следующего дня; неотвеченная проба закрывается пропуском.

**Задача.** Цикл `getUpdates` с хранением `offset` между тиками; два cron-тика
в одном `.mlog`; утренний предлагает руку и запрашивает предсказание, вечерний
собирает отклик; запись в базу.

**Сделано когда.** End-to-end на тестовом чате: предложение → предсказание →
отклик → строки в `trial` и `response`; обрыв сети на 10 минут не теряет ни
одного сообщения и не дублирует их; `offset` переживает перезапуск сервиса;
неотвеченная проба закрывается пропуском в 02:00 без ручного вмешательства;
секретов в коде нет; вывод модели не доходит до ответа без `escape_html`.

**Границы.** `src/telegram/`, `app.mlog`.

**Связь.** Потребитель Н1-05, поставщик данных для Н1-08. Блокирован языком:
**№592**.

## Н1-07 · Слепой логгер контекста

Labels: `наряд`, `волна-1`, `ядро`

**Шаг 0.** Сверить инвариант 2; убедиться, что в языке принят **№595**
(календарная арифметика).

**Факт.** Контекст пишется всегда и не показывается до записи отклика.
Вычисления идут в UTC, таймзона применяется только при отображении.

**Задача.** Время, окно суток, качество сна, фаза Луны и лунный день

отклика.

**Сделано когда.** Тест доказывает недоступность контекста через API до записи
отклика; фаза Луны сверена вторым независимым источником на 12 датах,
расхождение менее суток.

**Границы.** `src/context/`.

**Связь.** Поставляет признаки-кандидаты, в выборе не участвует. Блокирован
языком: **№595**.

## Н1-08 · Клапан честности

Labels: `наряд`, `волна-1`, `ядро`, `блокер`

**Шаг 0.** Убедиться, что Н1-05 и Н1-06 дают данные.

**Факт.** Без этого модуля система превращается в генератор совпадений.
Громкая деградация — принцип языка, и здесь он применяется к выводу.

**Задача.** Накопленный выигрыш бандита против случайного выбора; отчёт в чат
и CLI; прямая формулировка «сигнала нет» при отсутствии выигрыша; доля
пропусков по рукам отдельной строкой; источники «отклика в моменте»
показываются раздельно, без молчаливого смешения.

**Сделано когда.** На синтетике без сигнала отчёт говорит «сигнала нет»; на
синтетике с сигналом показывает выигрыш; все оценки выводятся диапазоном
low / expected / high, точечных нет; смена источника компонента видна
раздельно по источникам; строка пропусков присутствует в отчёте.

**Границы.** `src/honesty/`, `src/report/`.

**Связь.** Закрывает волну; без него волна не принимается. Зависимостей от
языка нет.
