# Worklog — append-only

Правило: нет следа здесь = не сделано. Строки не редактируются и не удаляются,
исправление дописывается новой строкой со ссылкой на исправляемую.

Формат строки:

```
YYYY-MM-DD · <наряд> · <что сделано> · <чем проверено> · <результат>
```

Результат — диапазон low / expected / high там, где это оценка, и точное
значение там, где это измерение.
