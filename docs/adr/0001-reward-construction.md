# ADR-0001 · Конструкция награды при неполных данных и источники «отклика в моменте»

Дата: 2026-10-05
Статус: принят (решение владельца @Miron, сформулировано в разборе концепции;
исполнение поручено агенту)
Затрагивает: инвариант 3 (AGENTS.md §5, концепция), схему `trial` (Н1-03),
бандит (Н1-05), Telegram-цикл (Н1-06), клапан честности (Н1-08)

## Контекст

Инвариант 3 в редакции 1 требует измерять «отклик в моменте» проекцией на
доминантную частоту. Спектральный контур появляется в языке с волны 30
(наряд №591), в применении — с фазы M2 (PPG через камеру). В волне 1 измерить
компонент проекцией нечем: инвариант нарушается буквально с первой пробы.
Отдельно требовалось правило счёта награды при отсутствующих компонентах:
«действие за 72 часа» может остаться без ответа, а молчание владельца не
должно ни выдумывать данные, ни терять их.

## Альтернативы

1. Компонент 0,2 в волне 1 всегда отсутствует, награда считается по двум
   компонентам. Отвергнуто: теряется немедленный сигнал, бандит до M2 слеп.
2. Подставлять субъективные шкалы без фиксации источника. Отвергнуто: тихое
   смешение источников — скрытая мутация измерения, дефект по духу §5.
3. Конструкция «флаги присутствия + нормированная сумма + два источника
   с объявленным приоритетом». Принята.

## Решение

- Три компонента награды пишутся всегда, каждый с флагом присутствия.
  Награда — взвешенная сумма присутствующих компонентов, нормированная на
  сумму их весов. Формула не меняется — меняются входы.
- «Отклик в моменте» имеет два источника с объявленным приоритетом: до M2 —
  субъективные шкалы сразу после пробы, с M2 — проекция на доминантную
  частоту. Приоритет у проекции. Проба хранит, какой источник использован.
- Клапан честности никогда не смешивает источники молча; при переходе на M2
  показывает их раздельно.
- Смена источника отдельного механизма не требует: экспоненциальный распад
  откликов за 60 дней поглощает переход за два месяца.
- Молчание владельца: проба не обновляется, пропуск записывается строкой;
  окно приёма отклика — до 02:00 следующего дня; у вопроса о действии
  собственный срок — 72 часа от пробы, неответ к сроку означает
  «компонент отсутствует», не ноль.

## Цена

- Смена источника в M2 видна в данных как разрыв ряда; клапан обязан
  показывать источники раздельно, иначе сравнение со случайным выбором
  некорректно.
- Нормированная сумма даёт неоднородную шкалу награды между пробами; клапан
  сравнивает со случайным выбором на тех же данных, поэтому смещения
  сравнения нет.
- До M2 компонент 0,2 опирается на самоотчёт; его смещения клапан ловит
  только косвенно — через сравнение со случайным выбором.
