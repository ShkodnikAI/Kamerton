# ADR-0003 — Слоты и ротация активного набора (ЧЕРНОВИК, ждёт утверждения порогов)

Статус: **черновик**. Режим «автоматическая ротация» выбран владельцем 2026-10-24
(issue #75). Числа ниже — предложение исполнителя; до их утверждения владельцем
автоматическая замена в код НЕ включена (активный набор меняется вручную через
`activate_arm` / `deactivate_arm`). Правило фиксируется ДО данных и после
утверждения меняется только новым ADR.

## Контекст

Практики идут параллельно по слотам (решение владельца 2026-10-23): в слоте не
больше **3 активных рук** (`slot.max_active`, проверка в `activate_arm`), каталог
шире активного набора. Оценка числа наблюдений на руку: примерно 0,98 / d² при
разбросе награды 0,25 — около 25 при d = 0,2, около 44 при d = 0,15; поэтому
больше трёх рук в слоте не успевают набрать данные.

Награда — общая валюта «движение» (0,2 момент / 0,3 следующий день / 0,5 действие
за 72 ч, ADR-0001) для всех слотов; владелец подтвердил 2026-10-24, что для новых
практик она не меняется.

## Предлагаемое правило

1. **Когда оценивать.** Рука может быть заменена только после ≥ 25 наблюдений
   (завершённые пробы хотя бы с одной присутствующей компонентой награды).
2. **Критерий замены.** По нормальной апостериорной оценке (как в бандите):
   вероятность того, что среднее руки ниже лучшей руки слота не менее чем на 0,10,
   ≥ 0,90. Тогда рука снимается с активного набора (данные остаются).
3. **Кто входит.** Следующая из каталога слота по порядку: приор-среднее по
   убыванию, затем id; только допущенная по согласию класса (`consent`), без
   исключений (в том числе для разведки).
4. **Темп.** Не больше одной замены в слоте за 14 суток.
5. **Возврат.** Снятая рука может вернуться кандидатом не раньше чем через 90 суток.
6. **Разведка.** Принудительная разведка (инвариант 5, каждый 5-й выбор) идёт по
   активному и допущенному набору и не отключается.
7. **Ручной приоритет.** Владелец в любой момент включает/выключает руку; свободные
   сессии (`kind = 'free'`) в данные бандита и клапана не входят.

## Открытые вопросы владельцу

- Утвердить или заменить числа 25 / 0,10 / 0,90 / 14 / 90.
- Какие три руки слота `breath` включаются первыми.
- Десять методик волны 1 пока без слота (cap на них не действует): относить ли их к
  отдельному слоту с тем же правилом.
