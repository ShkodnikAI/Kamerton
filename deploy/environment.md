## Metalogos

| Параметр | Значение |
| --- | --- |
| Репозиторий | `~/src/metalogos` (клон `ShkodnikAI/Metalogos-`) |
| Версия | 0.28.1, grammar rev 1 |
| Сборка | `cargo build --release -p metalogos-server` |
| Бинарник | `target/release/mlog`, 35 МБ |
| В PATH | `~/.local/bin/mlog` — симлинк, обновляется пересборкой |

**Важно, стоило двух лишних сборок.** `cargo build --release` из корня
собирает только `libmetalogos.rlib`. Исполняемый `mlog` объявлен в пакете
`metalogos-server/Cargo.toml`, и без `-p metalogos-server` не собирается.
Точек входа с именем `main.rs` у него нет — поиск по ним ничего не даёт.

Подтверждённые подкоманды: `run`, `check`, `audit`, `serve`, `test`,
`compile`, `repl`, `eval`, `resume`, `health`, `mcp-serve`, `ledger`.
Наряды волны 1 ссылаются на `check`, `audit`, `serve` — все существуют.

## Каталоги проекта

| Путь | Что |
| --- | --- |
| `~/src/kamerton` | Код приложения (из Windows: `D:\wsl\ubuntu\...`) |
| `/mnt/d/kamerton` | База и бэкапы — видны из Windows как `D:\kamerton` |

База лежит на стороне Windows намеренно: её должен забирать бэкап-скрипт
хоста, не залезая внутрь виртуального диска WSL.

## Переменные окружения процесса (Telegram)

В `/data/kamerton/env` нужны обе: `KAMERTON_TG_TOKEN` (читает код через
allowlist) и `TELEGRAM_BOT_TOKEN` (читает сам встроенный `send_message` из
окружения процесса; в allowlist намеренно не входит). Значение одно — токен
бота. Без второй отправка тихо превращается в [AUDIT]-заглушку.
`KAMERTON_TZ_OFFSET` (часы, МСК=3) — единственный источник «времени
владельца» (Н2-10): и расписание тиков, и даты проб считаются от него,
часовой пояс системы не используется.

## Границы для агента-исполнителя

- Разрешён каталог проекта `~/src/kamerton` и `/mnt/d/kamerton`.
- **Каталог языка `~/src/metalogos` — только чтение.** Правки в Metalogos
  идут нарядами волны 30 в его собственном репозитории, никогда отсюда.
- Пересборка языка после принятия волны 30 — отдельное действие владельца.

## Проверка среды одной командой

```bash
mlog --version && rustc --version && sqlite3 --version \
  && systemctl is-system-running; df -h / | tail -1
```

Ожидается: mlog 0.28.1, rustc 1.99.0, sqlite 3.46.1, система `running` или
`degraded` (в WSL часть юнитов не стартует — это норма), свободное место
на корне больше 100 ГБ.
