# Чек-лист деплоя волны 2 (Н2-02…Н2-08) после ворот M1

Составлен 2026-10-10, исполнитель команд — владелец. Команды подаются
**по одной** (блочная подача не успевает по sudo-паролю — известное
ограничение среды). У каждой команды указан ожидаемый ответ; ответ
сверяется глазами до перехода к следующему шагу. Написано по
`deploy/environment.md`, `deploy/install.sh`, `deploy/backup.sh`,
ADR-0002 и деплой-заметкам Н2-03…Н2-08 — факты сняты с кода репо,
не предположены. Рантайм: WSL2 Ubuntu, systemd, `/data/kamerton/`
(env, kamerton.db, копия app.mlog), сервис `kamerton.service`,
health `127.0.0.1:8461`.

## 2. Код: обновление чекаута и рантайм-копии app.mlog

```bash
git -C ~/src/kamerton fetch origin
git -C ~/src/kamerton pull --ff-only origin main   # ← main на 68991fd или новее
sudo bash ~/src/kamerton/deploy/install.sh          # ← идемпотентен
```

`install.sh` переложит свежий `app.mlog` в `/data/kamerton/`, env-файл
**не тронет** («exists, left untouched»), mlog v0.33.2 подтвердит пин
по SHA256, юнит сервиса перегенерирует идентично.

## 3. Env: KAMERTON_MINIAPP_TOKEN + allowlist (руки, деплой-заметка Н2-03)

env-файл сервера не перегенерируется — строку токена и рантайм-allowlist
дописать руками. SSOT `deploy/env.allowlist` имя уже содержит; рантайм-строка
на сервере собрана старым install.sh и его отстаёт.

```bash
openssl rand -hex 32                            # ← сгенерировать токен, сохранить
sudo nano /data/kamerton/env                    # две правки:
```

1. добавить строку `KAMERTON_MINIAPP_TOKEN=<сгенерированный токен>`;
2. в конец значения `METALOGOS_ENV_ALLOWLIST=...` дописать
   `,KAMERTON_MINIAPP_TOKEN` (имена через запятую, без пробелов).

```bash
sudo grep -c KAMERTON /data/kamerton/env        # ← 5 вхождений имён (tg, chat, db, tz, miniapp)
```

Токен Mini App — НЕ секрет чата: он идёт в URL страницы с телефона
(`?t=...`) и держится в закладке телефона.

В баннере ожидается: `route exec: denied`; env-gate соответствует
allowlist; scheduler active; счётчик маршрутов вырос против старого

неполностью (имя не дописано в allowlist), исправить и рестартовать.
